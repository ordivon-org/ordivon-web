Connectivity · Path evidence · Replaceable transport

Observe and recover the path without owning the task that uses it.

Ordivon Link owns facts and decisions about network paths between a user-controlled device and local, remote, or third-party endpoints. It observes, probes, compares, selects, connects, verifies, fails over, and recovers while keeping local Agent execution in Runtime and externally hosted capabilities in Edge.

Central question

Which network path is available, suitable, selected, connected, and recoverable?

Connectivity is not one boolean. A route may resolve DNS but fail QUIC, reach one endpoint but not another, work through a system VPN while degrading a local tunnel, or remain fast only for short responses. Link converts those observations into bounded evidence and explicit route identities.

It does not claim knowledge of the full packet path, mutate the root route automatically, or turn a network status console into a general control plane.
