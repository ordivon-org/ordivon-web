Computing stack · Research structure · Protocols · Conformance

Keep cognition, task continuity, semantic execution, and machine execution separable.

Ordivon Computing is the system-level research and construction root for persistent work performed with probabilistic models. It defines the boundaries among Model Runtime, Agent Host, Task Runtime, Semantic Kernel, Tool binding, Execution Runtime, and the classical operating system.

Central question

Which facts and contracts must remain stable when models, Hosts, tools, and execution backends change?

A model can reconstruct prose, but it cannot safely infer whether an external Effect already crossed a boundary, which concrete request was sent, whether the result is unknown, which evidence supports a Fact, or which durable Task state belongs to Host rather than a provider session.

The project turns those failure modes into explicit objects, executable state transitions, immutable receipts, and small reference systems. Real projects decide which abstractions survive.

Evolution

The mother project turns a broad computing thesis into tested component boundaries and executable research routes.

  1. Foundation
    Map the full agent-native computing stack.

    Fourteen layers separated hardware, models, Hosts, execution, world interfaces, and organization.

  2. Semantic Core
    Test the smallest non-reconstructable execution facts.

    Effect, Dispatch, unknown state, evidence, Fact admission, authority, and Journal replay became executable.

  3. Contracts
    Separate stable intent from concrete tools.

    EffectEnvelope, ToolContract, Binding, and admission were tested across Ordivon and a deterministic backend.

  4. Continuation
    Replace the model without replacing the Task.

    Codex/GPT and Hermes/DeepSeek continued the same Capsule and Context through the same semantic trajectory.

  5. Host extraction
    Move proven Task continuity into an independent state owner.

    After H2–H6 read, cognition, mutation, and recovery gates, Ordivon Host was extracted with history while Computing retained protocol and conformance authority.
