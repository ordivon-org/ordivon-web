Replace the model session without replacing the Task.

Ordivon Host owns persistent Goals, Tasks, Host events and projections, bounded cognition contexts, candidate admission, Effect proposals, Runtime Dispatch identities, verification receipts, and Task outcomes. Model sessions and Runtime processes remain replaceable dependencies rather than owners of continuity.

Central question

Which semantic state must survive when cognition, transport, and execution processes are replaced?

A model session can produce a decision, but it cannot own the long-lived identity of a Goal, the exact candidate set it was allowed to choose from, the Runtime Dispatch already attempted, the evidence that verified the result, or the frontier another process should continue.

The Host persists those semantic transitions while keeping process execution in Runtime and protocol research in Computing.

Current limits

Architectural proof is closed; product and operational proof remain open.

The current guarded mutation is a deliberately narrow proof-file workload, not general software-engineering execution.

No installable service, formal CLI, doctor, backup and restore, deploy and rollback, or user-facing Workbench exists on current main.

Whole-machine restart, abrupt power loss, remote Runtime partition, long-history cold start, distributed scheduling, and multi-Agent operation remain unproven.

Evolution

Host moved from a Computing incubator into an independently versioned state owner.

  1. H2–H4
    Prove read, cognition, and guarded mutation as separate durable slices.

    Repeated mechanics were reduced into one minimal Host transition kernel while semantic workload logic remained explicit.

  2. H5–H6
    Inject response loss and Runtime restarts.

    UNKNOWN delivery, correlated Job lookup, MCP readiness, and fresh-process recovery established the control-plane boundary.

  3. 27 Jul 2026
    Extract the complete Host history into ordivon-host.

    Computing retains protocol authority and conformance; Host now owns implementation and Host state.
