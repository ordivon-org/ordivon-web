# A3-2 — Security adversarial epistemics expression

## Upstream

Ordivon Studio revision `39153c98ad4823758c814ef0e1da18c336be769c` owns the cross-medium experiment (`research/expression/experiments/a32-adversarial-epistemics.md`). This Web candidate consumes the same Security AE0 evidence but uses Defender-near focalization rather than Motion's temporary privileged-audience view.

## Web hypothesis

The page should make epistemic entitlement visible through **document order**:

1. communicated claim;
2. UNKNOWN;
3. identical admitted context;
4. explicit inspection action;
5. execution receipt that is still not truth;
6. authoritative reveal;
7. only then, branch into hold/quarantine.

Before step 6, the hidden worlds are represented only as two neutral unresolved silhouettes. They must not receive truth-coded colors, labels, positions, or asymmetric detail.

## Falsifiers

Reject or revise if:

- the hidden healthy/compromised world can be inferred from pre-truth styling;
- the reader interprets UNKNOWN as a weak probability rather than absence of authoritative state;
- inspection appears to reveal truth merely because it executed;
- the page branches visually before `world-truth` arrives;
- mobile ordering reveals one outcome before establishing the shared evidence boundary;
- the treatment overwhelms the Security project page or reads as a universal Security law rather than one accepted AE0 experiment.

No population aesthetic preference claim is made.


## First composition correction

The first Web render used two equal unresolved world silhouettes behind the admitted evidence. That correctly represented two experimentally demonstrated hidden states, but equal geometry can be misread as an unsupported `50/50` prior. AE0 establishes epistemic indistinguishability, not a probability distribution.

The candidate therefore now states explicitly that the silhouettes are **possible experimental worlds, not equal probabilities**. This is a new class of aesthetic falsifier for the laboratory:

> visual balance can accidentally imply quantitative balance.

Symmetry is therefore not semantically free when the subject is uncertainty.


## Second composition correction — epistemic state is not severity

The first rendered candidate colored `truth: UNKNOWN` with the site's `signal` color. That visually biased an unresolved epistemic state toward danger / likely compromise even though AE0 provides no such posterior. The treatment was changed to the neutral-accent epistemic channel.

This adds another design law candidate:

> semantic color can accidentally imply likelihood or severity; `UNKNOWN` must not inherit the color of the feared outcome merely because the outcome is consequential.

## Decision

**Promote as a bounded Security-page expression, not as a universal Security law or reusable epistemics component.**

Reasons:

1. the section is source-bound to accepted AE0 evidence and adds no new Security authority;
2. the visual hierarchy materially represents information entitlement, not merely project status;
3. two real render reviews exposed and corrected semantic leaks from symmetry and color;
4. pre-truth styling does not encode healthy/compromised outcome state;
5. mobile document order preserves shared evidence → inspection → non-truth receipt → authoritative reveal → outcome;
6. the existing project mechanism remains available for operational inspection;
7. no human-preference or general deception-resistance claim is made.

The strongest local result is methodological: **visual semantics can function as implicit evidence and therefore must respect the same epistemic boundary as text and data.**
