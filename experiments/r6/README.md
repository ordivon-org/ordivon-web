# R6 encounter experiments

This directory contains Web-owned local experiment fixtures and contracts for Creative Alpha R6. It is not a public site surface and does not create a general analytics platform.

The Web boundary is deliberately small:

```text
experiment manifest
→ assignment with explicit probability / propensity
→ real Chromium encounter
→ exposure receipt
→ typed outcome receipt when requested
→ exact representative screenshot + visible-text digest
```

The first fixture proves instrumentation only. Synthetic browser participants are not human-experience evidence. Studio owns creative intervention semantics and consequence interpretation; Web owns the browser encounter and exposure facts.
## R6-C/D proven use

The same harness was used for the Studio-owned reveal-order experiment with a frozen `1080×1050` initial no-scroll viewport. The three variants contained identical full-page facts but exposed different first-viewport evidence sets. Web preserved assignment, propensity, actual browser exposure, full artifact evidence, viewport-intersecting evidence and representative pixels; Studio separately owned the oracle and consequence score.

This split is intentional:

- Web may prove **what was encountered**;
- Studio may interpret **what creative intervention that encounter represents**;
- an observer experiment may measure one named consequence;
- none of those facts alone establish human preference or universal design quality.
