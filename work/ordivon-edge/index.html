Central question

Which externally hosted capability should execute one bounded task and return a receipt or Artifact?

An external Fetch or browser snapshot crosses a different trust and failure boundary from local process execution. Requests can be duplicated, responses can be lost after commitment, leases can expire, policy can change, Artifacts can outlive receipts, and a release can time out after the control plane accepted it.

Edge makes those states explicit without becoming an open URL proxy, a local VPN controller, a general remote browser, or another Agent task runtime.

Strict boundary

Edge executes hosted capabilities; it does not decide local connectivity.

VPN detection, DNS and route inspection, path measurement, transport clients, local failover, and workstation status belong to Ordivon Link. Workspace, Job, process, Artifact, and local recovery lifecycle belong to Ordivon Runtime. Public presentation belongs to Ordivon Web.

Workers.dev, preview URLs, and public R2 access remain disabled. Edge is not a public proxy, subscription service, traffic reseller, credential broker, or remote shell.
