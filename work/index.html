Relationship

The stack is a graph of state owners, not one request pipeline.

Computing defines and falsifies contracts without owning production state. Host owns semantic Task continuity and calls replaceable models. Runtime commits local physical work. Link chooses and recovers network paths. Edge executes bounded hosted capabilities. Finance applies the stack to account decisions. Web projects their questions and evidence into a public interface.

Not every project calls every other project. A local Runtime task may need no Edge. A Link measurement may need no Host. Finance may adopt Runtime or Host contracts without becoming infrastructure. Source, tests, data, receipts, and each repository's current documents remain canonical.
