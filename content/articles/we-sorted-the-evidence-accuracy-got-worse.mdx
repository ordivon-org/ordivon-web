<InBrief claim="A representation can become mechanically perfect and semantically no better." evidence="E4 · preregistered/corrected P11 campaigns, mechanical permutation falsifier, exact owner report" scope="Finance six-dataset evidence ordering under P11">
  <p>The experiment kept the useful canonicalization mechanic and rejected the stronger claim that canonical order made the Agent understand the evidence better.</p>
</InBrief>

<h2 id="the-first-result-looked-like-a-context-engineering-law" data-toc="A tempting context law">The first result looked like a context-engineering law</h2>

<p>Earlier work had seen evidence-order sensitivity.</p>

<p>That is plausible. Language models consume sequences. Put the most important facts early and perhaps the Agent reasons better. Shuffle them and perhaps it misses dependencies.</p>

<p>Once you believe that, a product idea appears almost automatically:</p>

<blockquote>Canonicalize the evidence before every model call.</blockquote>

<p>Sort it. Normalize it. Build an identity map. Compile the Context into a stable order.</p>

<p>P11 tried to make that idea lose.</p>

<h2 id="mechanically-the-case-for-canonicalization-was-excellent" data-toc="Mechanical canonicalization worked">Mechanically, the case for canonicalization was excellent</h2>

<p>The first test did not involve a model at all.</p>

<p>Six Finance datasets were explicitly owner-declared as an unordered bundle.</p>

<p>Six objects have:</p>

<pre tabIndex={0}><code>{`6! = 720 permutations`}</code></pre>

<p>All 720 raw presentations had distinct byte digests.</p>

<p>Stable dataset-identity encoding collapsed them to <strong>one</strong> digest.</p>

<p>For hashing, cache identity, reproducibility, and replay, that is an unambiguous improvement.</p>

<div className="article-thesis"><p>But deterministic identity and semantic tractability are different objectives.</p></div>

<h2 id="global-sorting-immediately-failed-on-ordered-events" data-toc="Global sorting failed immediately">Global sorting immediately failed on ordered events</h2>

<p>The same normalizer cannot be applied blindly to everything.</p>

<p>P11 also took five Effect events with explicit <code>orderingDomain + sequence</code>.</p>

<p>Reconstructing them by sequence identity preserved the semantics.</p>

<p>Naively sorting the same events lexically was semantically valid in:</p>

<pre tabIndex={0}><code>{`0 / 120 permutations`}</code></pre>

<p>So there was already no such thing as a global “sort evidence” law.</p>

<p>Canonicalization needed owner-declared semantics before it could even claim mechanical correctness.</p>

<h2 id="then-the-first-model-campaign-turned-out-not-to-be-a-model-result" data-toc="The first campaign was invalid">Then the first model campaign turned out not to be a model result</h2>

<p>P11-v1 appeared to contain a large experiment: 144 cells across representations and orderings.</p>

<p>The Tool wire broke first.</p>

<p>The original 13-field function schema produced truncated DeepSeek arguments in <strong>141 of 144 cells</strong>.</p>

<p>That campaign was invalidated wholesale.</p>

<p>It was not rescored as evidence about context order.</p>

<blockquote>If the observation channel is broken, the Agent's apparent mistake is not yet evidence about the Agent.</blockquote>

<h2 id="the-second-campaign-found-an-even-more-interesting-confound" data-toc="The evaluator was ambiguous">The second campaign found an even more interesting confound</h2>

<p>P11-v2 repaired the Tool representation.</p>

<p>A large order effect still appeared.</p>

<p>Then the evaluator was inspected.</p>

<p>The prompt asked for the “tracking-error leader.” The oracle meant “the numerically largest latest <code>tracking_error_annualized_pct</code>.”</p>

<p>Those are not necessarily the same semantic instruction to a fresh Agent.</p>

<p>The campaign was retained as a diagnostic, not promoted as proof of order sensitivity.</p>

<p>The next experiment rewrote the target explicitly before touching the representation again.</p>

<h2 id="once-the-question-was-clear-the-ugly-baseline-won" data-toc="The raw baseline won">Once the question was clear, the ugly baseline won</h2>

<p>P11-v3 froze an unambiguous semantic target and compared three representations.</p>

<div tabIndex={0} className="article-data-table article-data-table-wide" role="table" aria-label="P11 representation results">
  <div className="article-data-row article-data-head" role="row"><span role="columnheader">Representation</span><span role="columnheader">Strict accepted</span><span role="columnheader">Distinct input digests</span></div>
  <div className="article-data-row" role="row"><strong role="cell">Raw six presentation orders</strong><span role="cell">44 / 48</span><span role="cell">6</span></div>
  <div className="article-data-row" role="row"><strong role="cell">Stable dataset-order list</strong><span role="cell">42 / 48</span><span role="cell">1</span></div>
  <div className="article-data-row" role="row"><strong role="cell">Identity map</strong><span role="cell">43 / 48</span><span role="cell">1</span></div>
</div>

<p>The canonical representations were mechanically cleaner.</p>

<p>They were not semantically more accurate.</p>

<p>The raw baseline scored highest.</p>

<h2 id="why-the-beautiful-abstraction-was-so-tempting" data-toc="Why the abstraction was tempting">Why the beautiful abstraction was so tempting</h2>

<p>Canonicalization has almost every property engineers like:</p>

<ul>
  <li>deterministic bytes;</li>
  <li>stable hashes;</li>
  <li>fewer cache identities;</li>
  <li>clean diffs;</li>
  <li>reproducible serialization;</li>
  <li>easier equality checks.</li>
</ul>

<p>Those are real benefits.</p>

<p>The mistake is letting one kind of order leak into another claim:</p>

<pre tabIndex={0}><code>{`mechanically canonical
≠ semantically clearer
≠ easier for a model
≠ more correct decision`}</code></pre>

<p>P11 retained the first property and rejected the automatic promotion to the others.</p>

<h2 id="ambiguity-can-masquerade-as-context-sensitivity" data-toc="Ambiguity can look like context sensitivity">Ambiguity can masquerade as context sensitivity</h2>

<p>The most useful result may not be the 44/48 score.</p>

<p>It is the sequence of failed explanations.</p>

<pre tabIndex={0}><code>{`Agent appears order-sensitive
→ wire representation was broken
→ fix wire
→ order effect still appears
→ semantic target was ambiguous
→ fix evaluator
→ canonicalization no longer wins`}</code></pre>

<p>If the team had stopped after either earlier campaign, it could have built a ContextCompiler to solve a measurement artifact.</p>

<h2 id="the-apparatus-was-deleted-after-the-result" data-toc="The apparatus was deleted">The apparatus was deleted after the result</h2>

<p>The round did not turn the experiment runner into permanent infrastructure.</p>

<p>The full executable/raw campaign remains Git-recoverable from an exact snapshot. The current Computing tree removed the apparatus and retained only the compact report, evidence, and contraction receipt.</p>

<p>The verification found zero current experiment executable-like source under the retained research tree.</p>

<p>This is the same burden-of-proof applied one level higher: a useful experiment does not automatically earn a permanent research service.</p>

<h2 id="what-survived" data-toc="What survived">What survived</h2>

<p>The final law is smaller than “order matters” and smaller than “normalize everything.”</p>

<blockquote>Before attributing model variance to presentation order, first freeze an unambiguous semantic question and independent oracle. Use deterministic canonical representation where the owner declares order irrelevant, but do not treat canonical bytes as proof of better semantic representation.</blockquote>

<p>No <code>EvidenceNormalizer</code>, <code>OrderService</code>, or <code>ContextCompiler</code> was promoted from P11.</p>

<h2 id="what-would-reopen-the-question" data-toc="What would reopen the question">What would reopen the question</h2>

<p>A future workload could still earn order-aware machinery if an unambiguous prospective experiment repeatedly shows a material semantic benefit that survives Provider changes and cannot be recovered by simpler prompt or evaluator clarification.</p>

<p className="article-closing">A system becomes easier to trust when it can keep the canonical hash and delete the story it wanted that hash to prove.</p>
