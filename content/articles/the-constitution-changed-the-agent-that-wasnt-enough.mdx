<h2 id="the-first-result-was-exactly-how-defaults-get-born" data-toc="How defaults get born">The first result was exactly how defaults get born</h2>

<p>Imagine giving an Agent a short constitution before it searches for a quantitative strategy.</p>

<p>The rules sound sensible. Prefer evidence over narrative. Respect holdouts. Penalize overfitting. Treat turnover and fragility as costs. Separate research from financial authority.</p>

<p>Now run a sealed experiment and watch the constitution arm choose a different candidate from the control.</p>

<p>Then reveal the holdout and discover that the constitution arm did better.</p>

<p>This is the moment when a useful research instrument can quietly become doctrine.</p>

<blockquote>It changed the Agent, and the result improved. Put it in every prompt.</blockquote>

<p>QB3b deliberately stopped one sentence earlier.</p>

<p>On its masked AAPL/QQQ/GLD carrier, constitution-only was materially less bad than control on the sealed outcome, but it was still negative. The experiment therefore recorded the result as a replication datum—not a default-context law.</p>

<h2 id="we-froze-the-treatment-instead-of-improving-it" data-toc="Freeze before replication">We froze the treatment instead of improving it</h2>

<p>The tempting next move would have been to read the first holdout, rewrite the constitution, add a better example, remove an awkward rule, or tune the wording around the failure.</p>

<p>That would answer a different question:</p>

<blockquote>Can we build a new prompt after seeing where the old prompt failed?</blockquote>

<p>QB3c asked the harder one:</p>

<blockquote>Does the same constitution-only treatment carry its benefit into a second sealed world?</blockquote>

<p>The treatment stayed unchanged. The formal round budget stayed at 18 trials per arm. Candidate language stayed the same. The second carrier changed to masked XAU/SPY/NVDA. Both arm selections had to become durable before either sealed holdout could be revealed.</p>

<h2 id="the-first-replication-attempt-was-thrown-away" data-toc="The first replication was thrown away">The first replication attempt was thrown away</h2>

<p>Before the market result could disagree with the theory, the experiment apparatus disagreed with itself.</p>

<p>The first QB3c attempt included dynamically created treatment directories inside the source-reservation proof. As the search ran, it created its own state and made the supposedly frozen source binding appear to change on resume.</p>

<p>Six trials per arm had completed. No holdout had been opened. The selections were not durable.</p>

<p>The run was aborted.</p>

<div className="article-thesis"><p>A broken experiment protocol is evidence about the experiment protocol. It is not negative evidence about the treatment being tested.</p></div>

<p>Nothing from that run was promoted into the treatment comparison.</p>

<h2 id="the-second-carrier-reversed-the-story" data-toc="The second carrier reversed the story">The second carrier reversed the story</h2>

<p>The corrected replication completed all 36 semantic trials—18 control, 18 constitution-only—and froze both selections before reveal.</p>

<p>Then the sealed result moved in the wrong direction.</p>

<p>Relative to control, the unchanged constitution treatment lost another 1.22 percentage points of cumulative return, reduced Sharpe by about 1.14, and consumed about 27.5% more Provider tokens.</p>

<p>One carrier had made the constitution look helpful. The next made it look harmful.</p>

<p>The correct conclusion was neither “the constitution works” nor “constitutions are bad.”</p>

<blockquote>The tested constitution did not show a stable monotonic benefit across the two sealed carriers.</blockquote>

<h2 id="behavior-change-is-not-benefit" data-toc="Behavior change is not benefit">Behavior change is not benefit</h2>

<p>This sounds obvious when stated after the experiment. It is easy to forget while designing Agent systems.</p>

<p>A system prompt can:</p>

<ul>
  <li>change which evidence the Agent attends to;</li>
  <li>change the candidate it selects;</li>
  <li>change how long it reasons;</li>
  <li>change the vocabulary of its explanation;</li>
  <li>change how conservative it appears.</li>
</ul>

<p>Every one of those is a real treatment effect.</p>

<p>None of them alone proves the treatment improves the objective we care about.</p>

<pre tabIndex={0}><code>{`prompt changes behavior
≠ behavior improves outcome
≠ improvement replicates
≠ treatment deserves default context`}</code></pre>

<h2 id="the-rulebook-moved-out-of-the-prompt" data-toc="The rulebook moved out of the prompt">The rulebook moved out of the prompt</h2>

<p>QB3c did not delete quantitative discipline.</p>

<p>It changed where that discipline is allowed to live.</p>

<p>Quant Bedrock remains useful as:</p>

<ul>
  <li>research equipment;</li>
  <li>strong baselines;</li>
  <li>priors an Agent may consult;</li>
  <li>falsifiers and evaluation constraints;</li>
  <li>institutional knowledge about leakage, turnover, sizing, survival, and attribution.</li>
</ul>

<p>What it did <strong>not</strong> earn was unconditional injection into every Agent turn as mandatory semantic context.</p>

<p>This is an Agent-first distinction. Good infrastructure should make useful structure available without deciding in advance that the Agent must carry all of it in cognition all of the time.</p>

<h2 id="why-a-compelling-rationale-is-weak-evidence" data-toc="Why rationale is weak evidence">Why a compelling rationale is weak evidence</h2>

<p>Constitutions are unusually vulnerable to post-hoc persuasion because their rules are usually defensible one by one.</p>

<p>“Avoid overfitting.” “Respect causal boundaries.” “Prefer out-of-sample evidence.” “Do not confuse a backtest with authority.”</p>

<p>These can all be good statements and still form a poor default context treatment for a particular Agent workload.</p>

<p>The relevant question is not whether a knowledgeable researcher can defend each sentence. It is whether the whole intervention produces stable marginal value after its token cost, interaction effects, and changed search path are counted.</p>

<h2 id="what-would-earn-default-status" data-toc="What would earn default status">What would earn default status</h2>

<p>The door is not closed.</p>

<p>A future context treatment could earn stronger status if it survives frozen replication across materially different carriers, providers, and tasks; if the benefit remains after token and search-cost accounting; and if a simpler on-demand equipment path cannot produce the same result.</p>

<p>Until then, the constitution is knowledge—not law.</p>

<p className="article-closing">A rulebook becomes dangerous when its plausibility is allowed to substitute for its replication history.</p>
